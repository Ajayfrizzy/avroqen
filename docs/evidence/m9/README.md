# M9 judge artifact manifest

**Status:** empty template. No screenshot, video, hash, hosted capture or public
artifact is recorded or implied here. Artifact capture and publication require
separate review and authorization.

For every future artifact, add one entry containing all of the following:

- Artifact filename or approved external reference
- Source commit SHA
- Capture date and time, including timezone
- Exact route
- Base origin
- Build mode, such as development or production
- Capture tool and exact command
- Viewport width and height in CSS pixels
- Browser name and exact version
- Operating system and physical device where applicable
- Device-pixel ratio and native or simulated zoom level
- JavaScript enabled or disabled
- Color scheme and reduced-motion preference
- Browser locale
- Evidence classification: `SAMPLE` only for the judge walkthrough
- SHA-256 of the exact stored artifact bytes
- Visible SAMPLE-label confirmation
- Privacy review result covering cookies, accounts, browser chrome, local paths,
  notifications, credentials, signatures, private source material and metadata
- Actual validation status: automated, manually inspected, physical-device,
  assistive-technology, native zoom, cross-browser, hosted, or not performed
- Reviewer and review date
- Explicit limitations and publication approval status

Do not add an entry until the artifact exists and its exact bytes have been
reviewed. Never reuse a deployment/initialization transaction as payment evidence,
and never classify a local fixture or sandbox result as public-chain settlement.
